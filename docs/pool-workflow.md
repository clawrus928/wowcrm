# 公海與線索池

線索與客戶各有獨立的已分配列表及公海列表。只有負責人可手動轉入公海；任何已登入用戶可領取公海紀錄，領取後成為新負責人。公海紀錄在領取前只供閱讀，不能一般編輯、刪除或轉換線索。轉入及領取均寫入審計紀錄，並保留前負責人、轉入時間和方式。

系統啟動時及其後每小時檢查一次：已分配的客戶和未轉換線索若 **30 個完整日** 沒有已完成跟進，便自動轉入公海。只計算建立時間、已完成跟進、舊系統匯入的 `lastFollowUpAt`，以及最近領取時間；未完成待辦不重置計時。已轉客戶的線索不回收。領取後由領取時間重新計算 30 日。

舊系統的公海資料可由管理 API 批次匯入，設 `inPool: true`、`previousOwner`、`poolEnteredAt` 和 `poolTransferMethod`；一般登入用戶不可直接以新增或修改端點建立公海狀態。舊系統使用者 ID 與 WOW CRM 帳號仍須在正式匯入前對應。此功能本身不匯入舊資料。
